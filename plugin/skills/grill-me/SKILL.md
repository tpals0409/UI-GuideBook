# Grill me

질문은 비용이에요. 답에 따라 산출물이 실제로 달라지는 질문만 해요.

## 순서

1. **먼저 읽어요.** 저장소·파일·앞선 대화에서 알 수 있는 건 묻지 않고, "이미 X라서 그건 고정할게요"로 확인만 해요.
2. **후보를 적어요(속으로).** 모르는 것 중 결과를 가르는 것만 남겨요. 답이 뭐든 산출물이 같다면 지워요.
3. **한 번에 하나씩, 최대 5개.** 보통 3개 안에 끝나요. 각 질문에 "답에 따라 무엇이 바뀌는지" 한 줄을 붙여요.
   - 예: "다크 모드가 필요해요? → 필요하면 어두운 테마 회사 30곳으로 후보를 좁혀요."
   - 선택지가 있으면 AskUserQuestion으로, 추천이 있으면 첫 번째에 "(추천)".
4. **확정 브리프.** 질문이 끝나면 아래 블록 하나로 정리하고 "이대로 갈까요?"만 물어요. 승인되면 그 뒤 작업의 유일한 입력이에요.

```
## 확정 브리프
- 무엇을: …
- 누구에게: …
- 꼭 지킬 것(고정값): …
- 바꿔도 되는 것: …
- 결정한 것: Q1 → 답, Q2 → 답 …
- 아직 모르는 것(기본값으로 감): …
```

## 규칙

- 사용자가 "그냥 알아서", "기본값으로"라고 하면 남은 질문을 모두 기본값으로 채우고 확정 브리프만 보여줘요.
- 같은 걸 다른 말로 두 번 묻지 않아요. 답이 애매하면 "A로 이해했어요"라고 적고 넘어가요.
- 질문 안에 설교·배경 설명을 넣지 않아요. 질문 한 문장 + 영향 한 줄.
- 다른 스킬이 호출했으면 확정 브리프를 돌려주고 끝나요. 작업은 그 스킬이 해요.
